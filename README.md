# Discord Fake Game Player (Game Variety Badge / Universalist)

Script otomatis untuk menyelesaikan badge Discord **Game Variety** (naik ke level **Universalist**) tanpa perlu mendownload atau menginstall game aslinya.

---

### ✨ Pembaruan & Fitur Utama

1. **Durasi Otomatis 20 Menit per Game**:
   - Discord server membutuhkan waktu bermain yang cukup (heartbeat telemetry) agar game benar-benar dihitung dan diregistrasi ke profil/badge. Durasi default otomatis disetel ke **20 menit**.
2. **Database Game Lengkap**:
   - `DETECTABLE_GAMES` langsung memuat **107+ Game Populer Terverifikasi** (termasuk semua game dari tangkapan layar Anda + game hits seperti CS2, Valorant, Cyberpunk 2077, Elden Ring, GTA V, dll.).
   - Tersedia opsi untuk memuat **seluruh database resmi Discord** (10.000+ game) dari `detectable_cache.json`.
3. **Random Shuffle (Pasti Semua Dapat)**:
   - Pemilihan game diacak (*random shuffle*), bukan urut abjad/daftar, namun menggunakan sistem antrean unik sehingga **setiap game pasti dimainkan** tanpa ada duplikasi.
4. **Pelacakan Riwayat Game (`played_history.json`)**:
   - Game yang sudah selesai dimainkan akan dicatat otomatis. Jika script dijalankan lagi, script akan memprioritaskan game yang belum pernah dimainkan.
5. **Indikator Progres Menit & Detik**:
   - Menampilkan status hitung mundur format waktu `19m 45s tersisa` beserta *progress bar*.

### 🚀 Cara Menjalankan

Buka terminal di folder ini dan jalankan salah satu:

#### Pilihan 1: Jalankan dengan Python (Direkomendasikan)
```bash
python fake_play.py
```

#### Pilihan 2: Jalankan dengan Node.js
```bash
node fake_play.js
```

#### Pilihan 3: Klik Ganda
Klik ganda file [run.bat](file:///c:/Users/User/Downloads/fake/run.bat) di Windows Explorer.
